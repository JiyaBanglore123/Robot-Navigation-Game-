HOW IT WORKS // AUTOMATA CONCEPTS

SLIDE 1 OF 3

1. INPUTS ARE MOVES

The input alphabet of our DFA is Σ = { U, D, L, R }. Each player keypress translates into a formal input symbol fed to the state machine:

▲ or W → U (Up)
▼ or S → D (Down)
◀ or A → L (Left)
▶ or D → R (Right)
SLIDE 2 OF 3

2. CELLS ARE STATES

Each safe grid cell directly maps to a distinct DFA state in Q:

  • q00: Starting state (Initial state → q0)
  • qrc: Row r, Column c coordinate state
  • q33: Goal destination (Accepting / Final state ∈ F)
  • Crash: Obstacle collision (Trap / Dead state)
SLIDE 3 OF 3

3. RULES ARE TRANSITIONS

The transition function δ(state, symbol) → next_state governs all outcomes:

• Open Path: Moves robot to new coordinate state.
↺ Boundary Wall: Self-loop transition. Robot stays in place (BLOCKED).
× Obstacle: Transitions to Crash trap state (STRING REJECTED).
